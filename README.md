# Installation
1. Clone or download the repo
2. Run `npm install`

This should install ColorThief through npm, which the program is primarily based on. 

# Usage
- run `node index.js image path`

# Notes
- majority of the current code is focused on printing out the output from ColorThief so it's more user-friendly than the hex codes alone

- future plans for the code involve making an optional additional argument that allows the number of colors for the palette to be chosen
