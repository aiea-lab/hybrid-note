#+Title: Symbolic Note Parser

## Overview

The Symbolic Note Parser epxlores how LLMs can identify speciifc symbolic structures in handwritten notes and represent them in a machine-readable JSON format. Unlike traditional extraction, this project focuses on preserving viusal structures such as bullets, arrows, boxes, circles, equations, and relationships between handwritten elements. 

The currnt prototype uses Claude to generate structured JSON frm handwritten note images and a Python validator to check the output against a predefined schema.

## Symbolic Structure Taxonomy 

The project defines 14 categories of handwritten symbolic structures along with their JSON representation. 

1. Bullet -- ListNode
2. Numbered List -- OrderedListNode
3. Checkbox -- TaskNode
4. Arrow -- Edge
5. Date -- DateNode
6. Highlight -- ImportanceNode
7. Underline -- EmphasisNode 
8. Box -- ContainerNode
9. Sketch -- ImageNode
10. Equation -- MathNode
11. Circle -- FocusNode 
12. Table -- TableNode
13. Graph/Chart -- GraphNode
14. Star/Exclamation -- ImportanceNode 


## Pipeline 



1. **Input:** Select a handwritten note image.
2. **Extraction:** Use Claude to identify symbolic elements and relationships.
3. **JSON Generation:** Save the extracted information as structured JSON.
4. **Validation:** Use `parser.py` to check JSON structure, node types, required fields, and relationships.

```text
Handwritten Note → Claude → Structured JSON → Python Validator → Validation Report
```

To run the validator from the project directory:

```bash
python3 parser.py
```

The Python script validates existing JSON outputs; image extraction is performed separately using Claude.

## Evaluation

The prototype was tested on five handwritten note pages from the ICDAR 2025 Handwritten Notes Understanding Challenge dataset.

- **135** elements and **54** relationships extracted.
- All five outputs contained valid JSON.
- **8** schema validation errors identified.
- Common errors included incorrect symbol classifications and inferred relationships without explicit visual arrows.
